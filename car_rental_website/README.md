# Blackline Auto — Car Rental Website

A responsive, single-page car rental/chauffeur inquiry website built with HTML5, CSS3, and vanilla JavaScript.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for remote vehicle photography and Google Fonts.

## Files
- `index.html` — semantic page structure, content, fleet cards, forms, metadata
- `style.css` — responsive styling and layout
- `script.js` — mobile navigation, fleet filters, selection, date validation, WhatsApp message creation
- `assets/logo.svg` — editable SVG logo

## Before publishing
- Replace Blackline Auto with your actual company name and brand.
- Replace the sample vehicle classes with only vehicles your company actually offers.
- Replace demo inventory with verified vehicle models, capacities, luggage data, transmission, fuel type, rates, and terms.
- Keep or remove service cards according to your real services.
- Confirm WhatsApp number `+923266438812`.
- Replace the email, address, business hours, and Google Maps search with your verified business information.
- Replace remote image URLs in `style.css` with locally hosted, properly licensed vehicle images if you need local assets/offline image loading.
- Update SEO metadata and social links for your company.

## Features
- Responsive mobile navigation
- Fleet filters for category, transmission, and price data
- Select a vehicle to prefill the inquiry form
- Required-field validation and return-date checks
- WhatsApp draft with URL-encoded inquiry details
- Accessible labels and live status messages
- Automatically updated copyright year
- Reduced-motion support

## Important behavior
This is a front-end-only site. It does not save submissions to a server or reserve vehicles. The form opens a WhatsApp message draft so the visitor can review and send it. Rental availability, final pricing, insurance, and terms must be confirmed by the business.
