IMRAN'S TAXI SERVICE — WEBSITE FILES

Files:
- index.html: complete single-page website
- styles.css: responsive design and brand styling
- script.js: mobile menu, service selection, booking form, WhatsApp message generation
- assets/promo-desktop.webp: supplied landscape promotional image
- assets/promo-mobile.webp: supplied portrait promotional image

HOW TO RUN
1. Extract the ZIP folder.
2. Keep index.html, styles.css, script.js and the assets folder together.
3. Open index.html in a browser, or upload the complete folder to your web host.

IMPORTANT CONFIGURATION
- Email is intentionally not invented. Replace the “Email address to be configured” placeholder and add the business email link once the real email address is available.
- Phone/WhatsApp currently uses +923188585480 as supplied.
- Booking requests open WhatsApp with a prefilled message; the customer must send it manually. This does not confirm a booking.
- Google Fonts and Google Maps require an internet connection.
- The two supplied images are used for the promotional desktop/mobile banner. The desktop promotional image is also reused in the About/hero background as supporting vehicle imagery.
