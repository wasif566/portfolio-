# Bright Future School website template

A responsive single-page school website built with HTML5, CSS3, and vanilla JavaScript.

## Files
- `index.html` — page content and admission inquiry form
- `style.css` — responsive styling
- `script.js` — mobile navigation, form validation, WhatsApp message generation, and current copyright year
- `assets/` — local SVG illustrations

## Before publishing
1. Replace “Bright Future School” with the real school name and logo.
2. Replace the sample address, email, opening hours, and other placeholder information.
3. Verify academic levels, facilities, notices, and admissions details; remove anything the school does not offer.
4. Update SEO title and meta description.
5. Confirm the WhatsApp number in `script.js` and the links in `index.html`.
6. Open `index.html` in a browser and test the form. Submission opens WhatsApp with a prefilled draft; the visitor must review and send it.

All illustrations are local SVG files. The font stylesheet uses Google Fonts when an internet connection is available; fallback fonts are included.
