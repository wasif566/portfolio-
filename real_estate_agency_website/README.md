# Haven & Co. Real Estate Website

A responsive single-page real estate agency website built with HTML5, CSS3, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. No build step or server is required.

## Before publishing
- Replace the demo agency name and logo with your actual brand.
- Replace all six clearly labelled demo property cards with verified listings, or remove them.
- Verify property availability, prices, measurements, address, phone number, email, opening hours, staff details, and all claims.
- The WhatsApp inquiry destination is configured as **+92 326 6438812**. Confirm this is the correct business number.
- Replace the Google Maps placeholder query with your verified office address.
- Replace `hello@example.com` with a monitored business email.
- Update the page title, description, and social-sharing metadata to match your business.
- Images load from Unsplash over the internet; an internet connection is required for those photos and Google Fonts. If you need a fully offline version, download licensed images and update the CSS image URLs.

## Included functionality
- Responsive desktop, tablet, and mobile layouts
- Mobile navigation menu
- Property filters for buy/rent, residential/commercial, and location
- Demo property save toggles
- Property inquiry buttons that preselect a listing
- Required field and email validation
- WhatsApp message generation using URL encoding
- SEO title, meta description, Open Graph metadata, and favicon
- Accessible labels, skip link, and reduced-motion support

## Important notes
- Sample property cards are explicitly labelled as demo content and must not be represented as real inventory.
- This is a front-end only website. Form details are not sent to a server; they are placed in a WhatsApp draft for the visitor to review and send.
- The map is a styled placeholder, not an embedded map of a verified office location.
