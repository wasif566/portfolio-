# Roofline Roofing & Gutter Care Website

Responsive static website starter made with HTML5, CSS3 and vanilla JavaScript.

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No build tools or backend are required. A static local server is recommended for testing.

## Files
- `index.html` — semantic page structure, metadata and sample structured data
- `style.css` — responsive layout, visual design, focus states and reduced-motion support
- `script.js` — mobile navigation, service prefill, gallery filters/lightbox, FAQ accordion, form validation and WhatsApp message creation
- `assets/images/` — original illustrative SVG scenes
- `assets/logo/` — sample logo and favicon
- `assets/icons/` — optional icons note

## Customize before publishing
This is a starter template, not a claim about a real company. Replace the sample business name, services, service area, hours, company background and contact information with verified details. Replace gallery illustrations with genuine project images before calling them completed work. Do not invent certifications, insurance, licences, reviews or fixed prices.

### WhatsApp and contact settings
Edit the `SITE_CONFIG` object at the top of `script.js`. WhatsApp is set to `923266438812` in international digits-only format. Update the email and update displayed phone/email copy in `index.html` too.

### Services, pricing and areas
Edit the cards and form options in `index.html`. Keep service button `data-service` values consistent with the quote form options. Package cards intentionally avoid made-up prices; add only approved pricing and explain access/property limitations. Update the service-area and opening-hours placeholders with confirmed details.

### Images and logo
Replace files under `assets/images/` and `assets/logo/` with images and branding you own or are licensed to use. Update paths and retain descriptive alt text. Current SVG gallery scenes are illustrations, not real project photographs.

### Form and privacy
The form validates required fields and opens WhatsApp with a prefilled message. It does not store or submit information to a server, and the user must review and send the message in WhatsApp. It intentionally has no fake upload feature. Add a proper privacy policy if required for your business.

## Test checklist
Check mobile navigation, service prefill buttons, required fields/email validation, WhatsApp URL encoding, gallery filters/lightbox, FAQ accordion, back-to-top and layouts at mobile/tablet/desktop sizes. Automated syntax checks do not replace manual browser testing on real devices.
