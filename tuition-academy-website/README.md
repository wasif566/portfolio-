# BrightPath Tuition Academy Website

A responsive single-page tuition academy website built with HTML5, CSS3, and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser. No build step or framework is required.

## Files
- `index.html` — page content, SEO metadata, course cards, enquiry form
- `style.css` — responsive design and styling
- `script.js` — mobile navigation, filters, course-to-form selection, validation, WhatsApp message generation
- `assets/` — locally stored SVG illustrations

## Before publishing
1. Replace “BrightPath Tuition Academy” with the real academy name.
2. Confirm the WhatsApp number in `script.js` and all `wa.me` / `tel:` links.
3. Replace example course cards with confirmed subjects and levels.
4. Add verified teacher profiles, real address, opening hours, and social links if available.
5. Test the WhatsApp redirect on a device with WhatsApp installed or WhatsApp Web access.

## WhatsApp enquiry
The form opens a prefilled WhatsApp message to `+923266438812`. It does not send automatically; the visitor reviews and sends it in WhatsApp. Enquiry is not confirmed enrollment.

## Notes
The teacher section and schedule are intentionally transparent placeholders. No teacher credentials, student results, testimonials, course fees, opening hours, or physical address have been fabricated.
